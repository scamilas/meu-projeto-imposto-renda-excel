# meu-projeto-imposto-renda-excel
Projeto DIO

📊 Ferramenta de Organização para Imposto de Renda – Excel

📌 Descrição
Projeto desenvolvido como parte do desafio da DIO, com o objetivo de criar uma ferramenta em Excel para organizar informações essenciais para a declaração de imposto de renda.

🎯 Objetivo
Facilitar o controle de rendimentos, despesas e bens ao longo do ano, garantindo organização, precisão e praticidade.

🛠 Funcionalidades
- Menu de navegação
- Validação de dados
- Links rápidos
- Formatação condicional
- Resumo automático dos valores
- Estrutura organizada por categorias

📂 Estrutura do Projeto
- /images → capturas de tela
- planilha-imposto-renda.xlsx → arquivo principal

🚀 Como usar
1. Abra o arquivo Excel.
2. Navegue pelo menu principal.
3. Preencha as informações nas abas correspondentes.
4. Consulte o resumo geral para visualizar totais.
